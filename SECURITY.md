# Security Policy

## Reporting a Vulnerability

Please report suspected vulnerabilities privately via
[GitHub Security Advisories](../../security/advisories/new).

Do **not** file public GitHub issues for security reports.

We will acknowledge receipt within 5 business days and aim to provide a status
update within 10 business days. Once a fix is available, we will coordinate a
disclosure timeline with the reporter.

## Supported Versions

Only the latest release on the `main` branch receives security fixes.
